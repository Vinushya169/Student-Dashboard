# 📊 Student Performance Factors Dashboard

> Analyzing 6607 Students Data to Understand What Drives Academic Success

🔗 **Live Demo:** https://student-dashboard-lzybsfcsewddd43vjkcwjx.streamlit.app
📂 **Dataset:** 6607 Rows x 20 Columns | StudentPerformanceFactors.xlsx

---

### 📌 About The Project
This project was developed to analyze the various socio-economic, personal, and academic factors that affect student performance. The dashboard helps educators, parents, and students to identify key performance drivers.

This is a **Data Analytics Internship Project** built using Python and Streamlit.

### 🎯 Problem Statement
What are the key factors that influence student exam scores? How do attendance, study hours, parental involvement, and other factors impact performance?

### ✨ Key Features
- 📈 **Interactive Dashboard** - User-friendly Streamlit UI
- 🔍 **Process Control Chart** - Monitor data quality and process stability
- 📊 **6607+ Student Records Analyzed**
- 📋 **20 Factors Analyzed** - Including Hours Studied, Attendance, Sleep Hours, Motivation Level etc.
- ⚡ **Real-time Filtering** - Filter by various factors
- ☁️ **Deployed on Streamlit Cloud** - Accessible anywhere

### 📈 Insights Found
- Students with >90% attendance score significantly higher
- Parental involvement has strong positive correlation
- Study hours between 3-5 hours show optimal performance
- Sleep hours (7-8 hrs) is crucial for top scores
